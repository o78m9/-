# عَودة — Copy Bible

> Stripe-level copy rules: ≤12 words/sentence · active voice · first-person CTAs · no filler · specific numbers beat adjectives.

---

## Voice Rules

| Rule                   | Example                                               |
| ---------------------- | ----------------------------------------------------- |
| ≤12 words per sentence | ✓ "مريض من كل اثنين لا يعود — ليس غضباً، بل نسياناً." |
| Active voice           | ✓ "عَودة يذكّره." ✗ "يتم التذكير بواسطة عَودة."       |
| First-person CTAs      | ✓ "أبدأ مجاناً" ✗ "ابدأ تجريبك"                       |
| Specific numbers       | ✓ "١٢٬٤٠٠ ريال" ✗ "إيرادات عالية"                     |
| No hedging             | ✓ "لا فاتورة." ✗ "قد لا تكون هناك فاتورة في حالة..."  |
