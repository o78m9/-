# Theme History — 12-Month Rolling

> Updated by `voice-of-customer` agent weekly. Tracks dominant themes per week so we can spot trend shifts before they hurt.

## Reading guide

- Each row = a week
- Columns = the 6 standard theme buckets + free-text
- A number = count of distinct customers/prospects who raised the theme that week
- A trend column shows the 4-week rolling direction (↑ ↓ →)
