# Daily Standup — Aooda Solo Founder Log

> **Period covered:** 2026-05-30 → 2026-06-29 (the 30-day plan).
> **Owner:** founder. Solo. Written, not mental.
> **Why this exists:** prevents drift. Daily 15-min ritual. Written every Sun-Thu morning before the first outreach call.
> **Linked:** `docs/30-day-plan.md §12` (template source), `docs/specs/outreach-pipeline-schema.md §6` (metric source).

---

## How to use this file

1. **When:** Sun–Thu mornings, before the first cold contact of the day. Max 15 minutes — if it takes longer, the day is already broken.
2. **Skip Fridays.** KSA rest day. Each Friday entry below is pre-filled with a "rest day" stub. Don't add notes; close the file.
3. **Saturdays:** optional. Use only if running a strategic session.
4. **Weekly retro:** every Thursday entry includes a 30-minute retro slot. Use it.
5. **Each day's slot has:**
   - **Yesterday** (max 3 bullets — what SHIPPED, not what was attempted).
   - **Today** (max 3 bullets — the ONE primary action + 2 secondary).
   - **Blocker** (one sentence, or "none").
   - **Metrics** (running tally: contacts logged / meetings booked / LOIs / signed).
   - **Mood (1-10)** (honest number, no commentary needed).
6. **Adding a new day** (if the template runs past 2026-06-29 or the founder needs to extend):
   - Run `node scripts/standup-new-day.mjs` from repo root.
   - Idempotent — if today's section already exists, it does nothing.
7. **End-of-week:** the Thursday retro slot is your weekly retro. Don't skip it.
8. **End-of-month (2026-06-29):** trigger the strategic offsite (per `30-day-plan.md §12`). 4 hours, solo, written, no laptop except for this doc and the board file.

---

## Honesty notes

- Mood 1-10 is for YOU. Nobody else reads it. Lying to yourself in this column kills the value of the practice.
- "Blocker: none" is suspicious 3 days in a row. Either you're not seeing the blocker or you're hiding it. The board file is the right place to surface hidden ones.
- Skipping Sun-Thu standups is a leading indicator of drift. Don't skip. If you wrote nothing yesterday, write "skipped yesterday" today and a one-sentence "why" — that itself is signal.
